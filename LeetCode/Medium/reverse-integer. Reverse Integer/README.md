## 문제 설명

부호 있는 32비트 정수 x가 주어졌을 때, x의 자릿수를 뒤집은 값을 반환하세요. x를 뒤집었을 때 값이 부호 있는 32비트 정수 범위 [-2^31, 2^31 - 1]을 벗어나면 0을 반환하세요.

환경이 64비트 정수(부호 있는 또는 부호 없는)를 저장할 수 없다고 가정합니다.

 

예시 1:

입력: x = 123
출력: 321

예시 2:

입력: x = -123
출력: -321

예시 3:

입력: x = 120
출력: 21

 

제약 조건:

-2^31 <= x <= 2^31 - 1

## 코드 리뷰

- 효율성: 보통
- 시간복잡도: O(N) (여기서 N은 정수의 자릿수)
- 더 나은 알고리즘: 문자열 변환 없이 수학적 연산(나눗셈과 나머지 연산)을 사용하여 O(1) 공간복잡도로 해결하는 방식이 문제의 제약사항(64비트 정수 사용 불가 환경 가정)에 더 부합합니다.

### 잘한 점

- 문자열 슬라이싱([::-1])을 활용해 코드가 매우 간결하고 읽기 쉽습니다.
- 음수 부호를 별도로 처리하여 자릿수 반전 시 부호가 유지되도록 정확히 구현했습니다.
- 32비트 정수 범위를 벗어날 경우 0을 반환해야 하는 제약 조건을 잘 만족했습니다.

### 개선할 점

- 정수를 문자열로 변환하고 다시 정수로 변환하는 과정에서 추가적인 메모리와 연산 비용이 발생합니다.
- 문제의 의도인 '64비트 정수 사용 제한'이라는 제약사항을 수학적 연산이 아닌 파이썬의 자동 임의 정밀도 기능을 통해 우회하고 있습니다.

### 상세 피드백

제출하신 코드는 Python의 강력한 문자열 슬라이싱 기능을 사용하여 가독성이 매우 높고 직관적으로 문제를 해결했습니다. 32비트 정수 범위를 초과하는지 여부를 마지막에 비교하여 처리한 점도 올바릅니다. 다만, 문제 설명에서 64비트 정수를 저장하지 않는 환경을 가정하고 있으므로, 내부적으로 큰 정수를 다루는 파이썬의 특성이나 문자열 변환 방식보다는 정수의 나머지(%)와 몫(//) 연산을 이용해 자릿수를 뒤집는 전통적인 수학적 접근 방식이 알고리즘 문제 해결 측면에서 더 권장됩니다. 또한 오버플로우를 미리 방지하면서 자릿수를 누적하는 방식으로 구현하면 더욱 견고한 코드가 됩니다.
