## 문제 설명

문자열 s가 주어질 때, 가장 긴 팰린드롬 부분 문자열을 반환하세요.

 

예제 1:

입력: s = "babad"
출력: "bab"
설명: "aba"도 유효한 답입니다.

예제 2:

입력: s = "cbbd"
출력: "bb"

 

제약 조건:

1 <= s.length <= 1000

s는 숫자와 영문자로만 이루어져 있습니다.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: 시간복잡도 O(N), 공간복잡도 O(N) (N은 문자열 길이, 변환된 문자열 길이는 2N+1)

### 잘한 점

- Medium 난이도 문제에 대해 O(N^2) DP나 중심 확장법 대신 O(N) Manacher's Algorithm을 정확히 구현하여 최적의 시간복잡도를 달성함
- mirror를 이용한 팰린드롬 반경 재사용 로직과 right/center 갱신 로직이 교과서적으로 정확하게 작성되어 edge case(인덱스 경계)도 문제없이 처리됨

### 개선할 점

- dp, max_center 같은 변수명이 Manacher 알고리즘의 의미(각 위치에서의 팰린드롬 반경)를 명확히 드러내지 못하고, 핵심 로직에 주석이 전혀 없어 유지보수나 타인의 코드 리뷰 시 이해하기 어려움
- 변환된 문자열 양끝에 경계 문자(예: '^', '$')를 추가하지 않아 while 루프 내에서 매번 배열 범위 검사를 수행해야 하는 사소한 비효율이 존재함

### 상세 피드백

이 풀이는 Manacher's Algorithm을 정확하게 구현한 것으로, Longest Palindromic Substring 문제에서 이론적으로 가장 빠른 O(N) 시간복잡도를 달성합니다. 문자열 사이에 '#'을 삽입해 홀수/짝수 길이의 팰린드롬을 통일된 방식으로 처리하는 전처리, 이전에 계산된 팰린드롬 반경을 활용해 중복 비교를 줄이는 mirror 최적화, right/center를 갱신하며 탐색 범위를 확장하는 로직 모두 교과서적인 Manacher 구현에 부합합니다. 직접 트레이스해본 결과 'babad', 'cbbd' 등 예시에서도 정확한 결과를 반환합니다. N<=1000 제약 조건을 고려하면 O(N^2) 중심 확장법이나 DP로도 충분히 통과 가능한 문제이지만, 이 풀이는 더 어려운 알고리즘을 선택해 최적의 복잡도를 구현했다는 점에서 매우 인상적입니다. 다만 변수명(dp, max_center 등)이 Manacher 알고리즘의 의미(팰린드롬 반경)를 바로 드러내지 못해 가독성이 다소 떨어지고, 핵심 로직에 대한 주석이 전혀 없어 알고리즘을 모르는 사람이 보면 이해하기 어렵습니다. 또한 '#' 구분자를 선택했는데 양 끝에 경계 문자(예: '^', '$')를 추가하지 않아 while 루프에서 매번 범위 체크(i - dp[i] - 1 >= 0, i + dp[i] + 1 < length)를 수행해야 하는 비효율이 약간 있습니다(이는 성능에 큰 영향은 없지만 코드를 더 복잡하게 만듦). 전반적으로 알고리즘 선택과 정확성 측면에서는 매우 우수하지만, 코드 가독성과 설명 측면에서 개선의 여지가 있습니다.
