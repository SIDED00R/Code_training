## 문제 설명

정수 n이 주어졌을 때, 이 정수가 4의 거듭제곱이면 true를 반환하고, 그렇지 않으면 false를 반환하세요.

정수 n이 4의 거듭제곱이라는 것은, n == 4^x를 만족하는 정수 x가 존재한다는 의미입니다.

 

예제 1:

입력: n = 16
출력: true

예제 2:

입력: n = 5
출력: false

예제 3:

입력: n = 1
출력: true

 

제약 조건:

-2^31 <= n <= 2^31 - 1

 

심화 문제: 반복문이나 재귀 없이 풀 수 있을까요?

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(1) 시간, O(1) 공간

### 잘한 점

- 루프/재귀 없이 비트 연산만으로 O(1) 시간에 해결하여 Follow-up 요구사항까지 만족
- n & (n-1) == 0으로 2의 거듭제곱 여부를, 0x55555555 마스크로 4의 거듭제곱 여부를 정확히 구분하는 효율적인 비트 트릭 사용
- n > 0 조건으로 음수와 0(2의 거듭제곱이 아닌 경우)에 대한 엣지케이스를 간결하게 처리

### 개선할 점

- 0x55555555 매직 넘버에 대한 주석이 전혀 없어 비트 마스크의 의도(1, 4, 16, 64 등 짝수 비트 위치)를 코드만 보고는 파악하기 어려움
- if 조건이 True면 return True, 아니면 return False 구조 대신 return 조건식 한 줄로 축약 가능하여 코드가 다소 불필요하게 길어짐

### 상세 피드백

비트 조작을 활용한 매우 효율적인 O(1) 풀이입니다. n & (n-1) == 0으로 n이 2의 거듭제곱인지 확인하고, 0x55555555(이진수로 0101...0101, 즉 1, 4, 16, 64 등 홀수 번째 비트가 아닌 짝수 위치에 1이 있는 수)와 AND 연산을 통해 4의 거듭제곱인지 추가로 검증합니다. 이는 2의 거듭제곱 중에서도 비트가 짝수 위치(0, 2, 4, ...)에 있는 경우만 4의 거듭제곱이라는 성질을 이용한 것입니다. 루프나 재귀를 전혀 사용하지 않아 문제의 Follow-up 요구사항까지 완벽히 충족하며, 시간/공간 복잡도 모두 O(1)로 이 문제에 대한 최적해에 해당합니다. n > 0 조건으로 음수와 0을 먼저 걸러내는 처리도 정확합니다. 다만 0x55555555라는 매직 넘버에 대한 주석이 없어 비트 마스크의 의미(짝수 비트 위치 검사)를 처음 보는 사람은 이해하기 어려울 수 있습니다.
