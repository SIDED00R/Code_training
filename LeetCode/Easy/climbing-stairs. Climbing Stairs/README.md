## 문제 설명

계단을 오르고 있습니다. 꼭대기에 도달하려면 n개의 계단을 올라가야 합니다.

한 번에 1계단 또는 2계단을 올라갈 수 있습니다. 꼭대기에 도달하는 방법은 총 몇 가지가 있을까요?

 

예제 1:

입력: n = 2
출력: 2
설명: 꼭대기에 도달하는 방법은 두 가지가 있습니다.
1. 1계단 + 1계단
2. 2계단

예제 2:

입력: n = 3
출력: 3
설명: 꼭대기에 도달하는 방법은 세 가지가 있습니다.
1. 1계단 + 1계단 + 1계단
2. 1계단 + 2계단
3. 2계단 + 1계단

 

제약 조건:

1 <= n <= 45

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: 시간복잡도: O(N), 공간복잡도: O(N)
- 더 나은 알고리즘: 공간복잡도를 O(1)로 줄이는 변수 2개만 사용하는 반복문 방식 (피보나치 수열 최적화)

### 잘한 점

- n = 1과 n = 2와 같은 작은 입력값에 대한 예외 처리가 정확합니다.
- 반복문(Bottom-Up 방식)을 사용하여 재귀 호출에 따른 오버헤드와 스택 오버플로우 위험을 방지했습니다.
- 변수명과 코드 구조가 간결하여 가독성이 매우 뛰어납니다.

### 개선할 점

- 모든 단계의 값을 배열에 저장하여 O(N)의 공간복잡도를 사용하지만, 직전 두 값만 있으면 되므로 공간복잡도를 O(1)로 줄일 수 있습니다.

### 상세 피드백

작성하신 코드는 동적 계획법(Dynamic Programming)의 기초를 아주 잘 이해하고 구현한 훌륭한 답안입니다. n = 1과 n = 2일 때의 예외 처리를 명확히 하고, 크기가 n + 1인 DP 테이블을 생성하여 중복 연산 없이 O(N)의 시간 안에 문제를 해결했습니다. 코드의 가독성도 높고 변수명도 직관적입니다. 다만, 이 문제는 이전 두 개의 값(dp[i-1]과 dp[i-2])만 알면 다음 값을 구할 수 있으므로, 배열 전체를 저장하는 대신 두 개의 변수만 활용하여 공간복잡도를 O(1)로 최적화할 수 있습니다.
