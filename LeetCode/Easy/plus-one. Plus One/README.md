## 문제 설명

정수 배열 digits로 표현된 큰 정수가 주어지며, 각 digits[i]는 그 정수의 i^th 자릿수입니다. 자릿수는 왼쪽에서 오른쪽으로 가장 높은 자리부터 가장 낮은 자리 순서로 정렬되어 있습니다. 이 큰 정수는 앞자리에 0이 오지 않습니다.

이 큰 정수에 1을 더하고 결과 자릿수 배열을 반환하세요.

 

예제 1:

입력: digits = [1,2,3]
출력: [1,2,4]
설명: 이 배열은 정수 123을 나타냅니다.
1을 더하면 123 + 1 = 124가 됩니다.
따라서 결과는 [1,2,4]가 되어야 합니다.

예제 2:

입력: digits = [4,3,2,1]
출력: [4,3,2,2]
설명: 이 배열은 정수 4321을 나타냅니다.
1을 더하면 4321 + 1 = 4322가 됩니다.
따라서 결과는 [4,3,2,2]가 되어야 합니다.

예제 3:

입력: digits = [9]
출력: [1,0]
설명: 이 배열은 정수 9를 나타냅니다.
1을 더하면 9 + 1 = 10이 됩니다.
따라서 결과는 [1,0]이 되어야 합니다.

 

제약 조건:

1 <= digits.length <= 100

0 <= digits[i] <= 9

digits는 앞자리에 0이 오지 않습니다.

## 코드 리뷰

- 효율성: 보통
- 시간복잡도: O(N) ~ O(N^2) (CPython의 큰 정수 <-> 문자열 변환은 digit 수에 대해 선형이 아닐 수 있음, N은 digits 길이)
- 더 나은 알고리즘: 배열을 뒤에서부터(마지막 인덱스부터) 순회하며 1을 더하는 캐리(carry) 방식으로 푸는 것이 정석입니다. digits[i]가 9면 0으로 바꾸고 캐리를 유지하며 앞으로 이동하고, 9가 아니면 1을 더하고 즉시 반환합니다. 모든 자리가 9인 경우에만 맨 앞에 1을 삽입합니다. 이렇게 하면 문자열/정수 변환 없이 O(N) 시간, O(1) 추가 공간(최악의 경우 결과 배열 크기 N+1)으로 처리할 수 있어 Array/Math 태그의 의도에 부합합니다.

### 잘한 점

- 코드가 간결하고 정답을 정확히 도출함 (Python의 큰 정수 지원을 활용해 overflow 걱정 없이 동작)
- 엣지 케이스인 [9] -> [1,0] 같은 캐리 전파 상황도 정수 변환 덕분에 자연스럽게 처리됨

### 개선할 점

- Array/Math 태그의 학습 의도(자리별 순회와 캐리 처리)를 우회하여 알고리즘적 사고 연습이 되지 않음
- 리스트->문자열->정수->문자열->리스트로 여러 번 변환하여 불필요한 오버헤드와 가독성 저하가 발생함
- 변수명이 없고 한 줄에 모든 로직이 압축되어 있어 디버깅이나 유지보수가 어려움

### 상세 피드백

주어진 digits 배열을 문자열로 합친 뒤 Python의 임의 정밀도 정수로 변환하여 +1을 하고 다시 문자열로 쪼개 리스트로 만드는 방식입니다. 결과는 정확하고 짧은 한 줄로 작성된 점은 영리하지만, 이 문제의 알고리즘 태그가 Array/Math인 이유는 '배열 순회와 캐리 처리'라는 핵심 로직을 연습시키려는 것인데, 이 코드는 Python 내장 정수형의 임의 정밀도 기능에 전적으로 의존해 그 학습 목적을 우회합니다. 또한 int<->str 변환은 자릿수가 커질수록 성능 저하가 발생할 수 있고(특히 과거 CPython 버전에서는 큰 정수의 10진 변환이 비선형적), leading zero가 없다는 제약 덕분에 이번 문제에서는 안전하지만 범용적인 큰 정수 연산 패턴으로는 비효율적입니다. 전통적인 역순 순회 + 캐리 방식이 더 명확하고 효율적이며 면접/코딩테스트 관점에서 기대되는 풀이에 가깝습니다. 가독성 측면에서도 한 줄에 map, join, str, int, list가 중첩되어 있어 가독성이 떨어지고, 각 단계에서 리스트-문자열-정수-문자열-리스트로 여러 번 자료형을 왕복 변환하면서 불필요한 메모리 할당이 발생합니다.
