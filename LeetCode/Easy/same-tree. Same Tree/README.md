## 문제 설명

두 이진 트리 p와 q의 루트가 주어졌을 때, 두 트리가 같은지 아닌지를 확인하는 함수를 작성하세요.

두 이진 트리가 구조적으로 동일하고 노드들의 값이 같다면, 두 트리는 같다고 간주됩니다.

 

예제 1:

Input: p = [1,2,3], q = [1,2,3]
Output: true

예제 2:

Input: p = [1,2], q = [1,null,2]
Output: false

예제 3:

Input: p = [1,2,1], q = [1,1,2]
Output: false

 

제약 조건:

두 트리의 노드 개수는 [0, 100] 범위입니다.

-10^4 <= Node.val <= 10^4

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: 시간복잡도: O(N) (N은 두 트리 중 작은 쪽, 혹은 min(N,M)의 노드 수), 공간복잡도: O(H) (H는 트리의 높이, 재귀 호출 스택 깊이, 최악의 경우 O(N))

### 잘한 점

- O(N) 시간복잡도로 모든 노드를 한 번만 방문하는 최적의 접근 방식을 사용함
- None 처리, 값 비교, 재귀 호출 순서가 명확하고 모든 엣지 케이스를 빠짐없이 처리함
- 코드가 짧고 가독성이 높아 한 번에 이해 가능함

### 개선할 점

- 마지막 else 블록은 불필요하며, 'return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)' 한 줄로 끝내고 함수 끝에 'return False'를 두거나 애초에 if-else 구조를 단순화할 수 있음 (가독성보다는 미세한 스타일 개선 여지)
- 노드 수가 매우 크고 트리가 한쪽으로 치우친 극단적인 경우 재귀 깊이 제한에 걸릴 수 있으나, 이 문제 제약조건 내에서는 실질적인 문제가 되지 않음

### 상세 피드백

이 풀이는 재귀를 이용한 DFS(전위 순회) 방식으로 두 트리를 동시에 탐색하며 비교하는 전형적이고 정석적인 방법입니다. 각 노드를 정확히 한 번씩만 방문하므로 시간복잡도는 O(N)으로 최적입니다. 공간복잡도는 재귀 호출 스택에 의해 결정되며, 균형 트리라면 O(log N), 한쪽으로 치우친 트리라면 최악의 경우 O(N)입니다.

로직 측면에서도 기저 조건(base case) 처리가 정확합니다. 1) 둘 다 None이면 True, 2) 한쪽만 None이면 False, 3) 값이 다르면 False, 4) 값이 같으면 좌/우 서브트리를 재귀적으로 비교하는 구조로 모든 엣지 케이스(빈 트리, 구조가 다른 트리, 값만 다른 트리)를 빠짐없이 커버합니다.

다만 BFS(반복문 + 스택/큐)로 풀면 재귀 깊이 제한(Python 기본 1000) 문제를 피할 수 있다는 점에서 극단적으로 노드 수가 많고 한쪽으로 치우친 트리의 경우 재귀 방식이 RecursionError를 일으킬 가능성이 있으나, 이 문제의 제약조건(노드 수 0~100)에서는 전혀 문제가 되지 않습니다. 전반적으로 이 문제의 최적해에 해당하는 풀이입니다.
