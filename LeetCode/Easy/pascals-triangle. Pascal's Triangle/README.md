## 문제 설명

정수 numRows가 주어졌을 때, 파스칼의 삼각형의 첫 numRows개 행을 반환하세요.

파스칼의 삼각형에서는 아래 그림과 같이 각 숫자가 바로 위에 있는 두 숫자의 합입니다:

 

예제 1:

입력: numRows = 5
출력: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]

예제 2:

입력: numRows = 1
출력: [[1]]

 

제약 조건:

1 <= numRows <= 30

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: 시간복잡도 O(numRows^2), 공간복잡도 O(numRows^2)

### 잘한 점

- 핵심 로직인 '이전 행의 인접한 두 원소를 더해 현재 행을 만드는' 파스칼 삼각형의 본질을 정확히 구현함
- 시간/공간복잡도가 이 문제에서 달성 가능한 최적 수준(O(N^2))을 만족함
- numRows=1, numRows=2 등 작은 입력에 대한 엣지케이스를 명시적으로 처리하여 인덱스 에러 없이 안전하게 동작함

### 개선할 점

- i==0, i==1에 대한 특수 분기 처리가 불필요하며, 일반화된 루프 하나로 통합 가능해 코드가 다소 중복됨
- 리스트 컴프리헨션을 활용하면 더 간결하고 Pythonic하게 작성할 수 있는데, append를 반복 호출하는 방식으로 작성되어 있음
- 변수명 now_ans가 의미를 바로 전달하기에는 다소 모호함 (current_row, new_row 등이 더 명확함)

### 상세 피드백

파스칼 삼각형은 전체 원소 개수가 이미 O(numRows^2)이므로, 모든 원소를 한 번씩 채우는 이 풀이의 시간복잡도 O(numRows^2)는 이론적으로 최적입니다. 공간복잡도 역시 결과 자체를 저장해야 하므로 O(numRows^2)이 불가피하며, 이를 줄이기 위한 별도의 알고리즘적 개선은 필요하지 않습니다.

다만 코드 구조 면에서 i==0, i==1을 별도로 분기 처리한 점은 다소 장황합니다. 어떤 i에서도 동일한 로직(now_ans = [1] + [중간 합산] + [1])을 적용할 수 있도록 일반화하면, i==1일 때 for j in range(0)이 자연스럽게 빈 루프가 되어 [1, 1]이 생성되므로 특수 케이스 분기가 불필요해집니다. 예를 들어:
```python
answer = [[1]]
for i in range(1, numRows):
    prev = answer[-1]
    row = [1] + [prev[j] + prev[j+1] for j in range(len(prev)-1)] + [1]
    answer.append(row)
```
이렇게 하면 코드 라인 수가 줄고 분기 로직이 사라져 가독성이 향상됩니다. 전체적으로 정답 로직 자체는 정확하고 효율적이나, 불필요한 조건 분기로 인해 코드가 다소 중복되어 보입니다. 변수명 now_ans는 current_row 등으로 바꾸면 의미가 더 명확해질 것입니다.
