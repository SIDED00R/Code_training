## 문제 설명

정수 n이 주어졌을 때, 이 수가 2의 거듭제곱이면 true를 반환하고, 그렇지 않으면 false를 반환하세요.

정수 n이 2의 거듭제곱이라는 것은 n == 2^x를 만족하는 정수 x가 존재한다는 뜻입니다.

 

예제 1:

입력: n = 1
출력: true
설명: 2^0 = 1

예제 2:

입력: n = 16
출력: true
설명: 2^4 = 16

예제 3:

입력: n = 3
출력: false

 

제약 조건:

-2^31 <= n <= 2^31 - 1

 

후속 질문: 반복문이나 재귀 없이 풀 수 있을까요?

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(1) 시간, O(1) 공간

### 잘한 점

- 비트 연산을 이용해 O(1) 시간/공간으로 문제를 해결한 최적의 접근
- n > 0 조건으로 음수 및 0을 올바르게 제외하여 엣지케이스를 정확히 처리함
- follow-up 요구사항인 '루프/재귀 없이 풀기'를 충족함

### 개선할 점

- if-return True/False 패턴 대신 조건식을 바로 return하면 코드가 더 간결해짐
- n & (n - 1)에 괄호를 명시적으로 추가해 연산자 우선순위에 대한 오해를 방지하면 가독성이 향상됨

### 상세 피드백

비트 조작을 활용한 전형적인 최적 풀이입니다. 2의 거듭수는 이진수로 표현했을 때 비트가 정확히 하나만 1이라는 성질을 이용해, n & (n-1)이 0이 되는지 확인하는 방식입니다. 예를 들어 n=8(1000)이면 n-1=7(0111)이고, 둘을 AND 연산하면 0000이 되어 참이 됩니다. n>0 조건을 함께 체크해 음수나 0(제약조건상 n이 음수도 가능하므로 중요)인 경우를 올바르게 걸러냅니다. 시간/공간복잡도 모두 O(1)로 loop/recursion 없이 처리하라는 follow-up 요구사항까지 만족시키는 이상적인 풀이입니다. 다만 코드 스타일 면에서 'return True/False' 대신 'return n > 0 and n & (n - 1) == 0' 한 줄로 바로 반환하면 더 간결해집니다. 또한 연산자 우선순위상 &가 ==보다 낮아 실제로는 n & ((n-1) == 0)으로 평가될 위험이 있는데, 파이썬에서는 ==가 &보다 우선순위가 높아 의도대로 동작하지만, 괄호를 명시해 (n & (n-1)) == 0으로 작성하면 가독성과 의도 전달이 더 좋아집니다. 전반적으로 알고리즘 선택과 효율성 면에서는 완벽하며, 약간의 스타일 개선만 하면 됩니다.
