## 문제 설명

이 문제는 이 문제의 이지 버전입니다. 차이점은 문자열 길이의 합과 테스트 케이스 수에 대한 제약 조건뿐입니다. 이 문제의 모든 버전을 해결해야만 해킹을 할 수 있습니다. 알파벳 소문자로 이루어진 문자열 $s$가 주어집니다. 다음 조건들을 만족하는 가장 긴 문자열 $t$를 찾으세요.     $t$의 길이는 $s$의 길이를 초과하지 않습니다.   $t$는 팰린드롬(palindrome)입니다.   $t = a + b$ (여기서 " $+$ "는 이어붙이기를 의미함)를 만족하는 두 문자열 $a$와 $b$ (비어 있을 수도 있음)가 존재하며, $a$는 $s$의 접두사(prefix)이고 $b$는 $s$의 접미사(suffix)입니다.

## 입력

입력은 여러 개의 테스트 케이스로 구성됩니다. 첫 번째 줄에는 테스트 케이스의 개수를 나타내는 단 하나의 정수 $t$ ($1 \leq t \leq 1000$)가 주어집니다. 이어서 다음 $t$개의 줄에는 각각 하나의 테스트 케이스가 설명되어 있습니다. 각 테스트 케이스는 알파벳 소문자로 이루어진 비어 있지 않은 문자열 $s$입니다. 모든 테스트 케이스에 대한 문자열 길이의 합은 $5000$을 넘지 않는다고 보장됩니다.

## 출력

각 테스트 케이스에 대해, 위에서 설명한 조건을 만족하는 가장 긴 문자열을 출력하시오. 가능한 정답이 여러 개 존재한다면, 그중 아무거나 하나를 출력하시오.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(N)

### 잘한 점

- Manacher 알고리즘을 정확하고 간결하게 구현하여 O(N) 시간에 문제를 해결했습니다.
- 양 끝의 공통 팰린드롬 부분을 미리 걷어내고 남은 부분에 대해서만 알고리즘을 적용하여 불필요한 연산을 줄였습니다.
- 함수 분리가 잘 되어 있어 코드의 구조가 명확하고 가독성이 좋습니다.

### 개선할 점

- 문제의 난이도(Codeforces 1500, Easy version)에 비해 Manacher 알고리즘은 다소 과한(Overkill) 면이 있을 수 있습니다.
- 변수명(t, r, c, bp, bs 등)이 축약어로 되어 있어 처음 코드를 보는 사람이 직관적으로 이해하기에 약간의 노력이 필요합니다.

### 상세 피드백

제출된 코드는 Manacher 알고리즘을 활용하여 문자열의 접두사와 접미사가 일치하는 부분을 제외한 나머지 중앙 부분에서 가장 긴 팰린드롬 접두사 혹은 접미사를 찾고 있습니다. 양 끝에서부터 같은 문자를 먼저 매칭시켜 나가는 전처리 덕분에 Easy version의 제한 조건 안에서 매우 빠르게 동작합니다. Manacher 알고리즘의 시간복잡도는 O(N)이며, 전체적인 로직이 수학적으로 타당하고 깔끔하게 구현되어 있습니다. 다만 이 문제는 Easy version으로 길이가 최대 5000 이하이기 때문에 간단한 투 포인터와 문자열 비교(또는 Z-algorithm, KMP 등)로도 충분히 O(N^2) 또는 O(N)에 풀 수 있지만, Manacher 알고리즘을 적용한 풀이 또한 훌륭한 접근입니다.
