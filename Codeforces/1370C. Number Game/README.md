## 문제 설명

Ashishgup와 FastestFinger는 게임을 합니다. 그들은 숫자 $n$으로 시작하고 차례로 플레이합니다. 각 차례에 플레이어는 다음 중 하나의 이동을 할 수 있습니다: $n$을 $1$보다 큰 홀수 약수 중 하나로 나누기. $n$이 $1$보다 크면 $n$에서 $1$을 빼기. 숫자의 약수에는 그 숫자 자체도 포함됩니다. 이동을 할 수 없는 플레이어가 게임에서 집니다. Ashishgup가 먼저 이동합니다. 두 플레이어가 최적의 전략으로 플레이할 경우 게임의 승자를 결정하세요.

## 입력

첫 번째 줄에는 단일 정수 $t$ ($1 \leq t \leq 100$) 가 포함되어 있습니다 — 테스트 케이스의 수입니다. 테스트 케이스의 설명이 이어집니다. 각 테스트 케이스의 유일한 줄에는 단일 정수 $n$ ($1 \leq n \leq 10^9$) 가 포함되어 있습니다.

## 출력

각 테스트 케이스에 대해, 그가 이기면 " Ashishgup "을 출력하고, 그렇지 않으면 " FastestFinger "를 출력합니다 (따옴표 없이).
