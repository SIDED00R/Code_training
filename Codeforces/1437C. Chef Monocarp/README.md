## 문제 설명

셰프 모노카프(Monocarp)는 방금 $n$개의 요리를 오븐에 넣었습니다. 그는 $i$번째 요리의 최적 조리 시간이 정확히 $t_i$분이라는 것을 알고 있습니다. 모노카프는 양의 정수 분 $T$마다 오븐에서 요리를 **최대 하나** 꺼낼 수 있습니다. 만약 $i$번째 요리가 어떤 분 $T$에 꺼내어진다면, 그 요리의 불쾌함 값은 $T$와 $t_i$의 절대값 차이인 $|T - t_i|$가 됩니다. 요리가 일단 오븐 밖으로 나오면, 다시 집어넣을 수 없습니다. 모노카프는 모든 요리를 오븐에서 꺼내야 합니다. 모노카프가 얻을 수 있는 총 불쾌함 값의 최솟값은 얼마입니까?

## 입력

첫 번째 줄에는 테스트 케이스의 수를 나타내는 단일 정수 $q$ ($1 \le q \le 200$)가 주어집니다. 그 후 $q$개의 테스트 케이스가 이어집니다. 각 테스트 케이스의 첫 번째 줄에는 오븐에 있는 요리의 개수를 나타내는 단일 정수 $n$ ($1 \le n \le 200$)이 주어집니다. 테스트 케이스의 두 번째 줄에는 각 요리의 최적 조리 시간을 나타내는 $n$개의 정수 $t_1, t_2, \dots, t_n$ ($1 \le t_i \le n$)이 주어집니다. 모든 $q$개의 테스트 케이스에 대한 $n$의 합은 $200$을 넘지 않습니다.

## 출력

각 테스트 케이스마다 단 하나의 정수를 출력한다. 이는 모노카르프가 모든 요리를 오븐에서 꺼낼 때 얻을 수 있는 최소 총 불쾌함 값이다. 모노카르프는 오직 양의 정수 분에만 요리를 꺼낼 수 있으며, 어떤 분에도 두 개 이상의 요리를 꺼낼 수 없음을 기억하라.
