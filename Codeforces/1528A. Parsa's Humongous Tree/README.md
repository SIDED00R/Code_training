## 문제 설명

파르사(Parsa)는 $n$개의 정점으로 이루어진 엄청나게 큰 트리를 가지고 있습니다. 각 정점 $v$에 대해 그는 두 정수 $l_v$와 $r_v$를 적어두었습니다. 파르사의 트리를 더욱 웅장하게 보이게 하기 위해, 니마(Nima)는 트리의 아름다움이 최대가 되도록 각 정점 $v$에 수 $a_v$ ($l_v \le a_v \le r_v$)를 배정하려 합니다. 니마의 미적 감각은 다소 기괴합니다. 그는 트리의 아름다움을 트리의 모든 간선 $(u, v)$에 대한 $|a_u - a_v|$의 합으로 정의합니다. 파르사의 트리는 너무 크기 때문에 니마 혼자서는 그 아름다움을 최대화할 수 없습니다. 여러분의 임무는 파르사 트리에서 얻을 수 있는 최대 아름다움을 찾는 것입니다.

## 입력

첫 번째 줄에는 테스트 케이스의 수를 나타내는 정수 $t$ $(1\le t\le 250)$가 주어집니다. 그고 나서 각 테스트 케이스의 설명이 주어집니다. 각 테스트 케이스의 첫 번째 줄에는 파르사의 트리의 정점 개수를 나타내는 단일 정수 $n$ $(2\le n\le 10^5)$이 주어집니다. 이어서 주어지는 $n$개의 줄 중 $i$번째 줄에는 두 정수 $l_i$와 $r_i$ $(1 \le l_i \le r_i \le 10^9)$가 주어집니다. 다음 $n-1$개의 줄 각각에는 파르사의 트리에서 정점 $u$와 $v$ 사이에 간선이 있음을 의미하는 두 정수 $u$와 $v$ $(1 \le u , v \le n, u\neq v)$가 주어집니다. 주어진 그래프는 항상 트리임이 보장됩니다. 모든 테스트 케이스에 대한 $n$의 합은 $2 \cdot 10^5$을 넘지 않음이 보장됩니다.

## 출력

각 테스트 케이스마다 파르사(Parsa)의 트리에서 얻을 수 있는 가능한 최대 아름다움(beauty)을 출력하시오.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(N)

### 잘한 점

- 재귀를 사용하지 않고 반복문으로 트리 순회 및 DP를 구현하여 파이썬의 재귀 제한 문제를 효과적으로 방지함
- sys.stdin.buffer.read()를 사용하여 대량의 입력 데이터를 매우 빠르게 처리함
- 트리 DP의 상태 전파를 $O(N)$ 시간에 정확하게 구현하여 시간 초과 없이 통과함

### 개선할 점

- 변수명이 단일 문자로 이루어진 경우가 많아 코드의 가독성이 다소 떨어짐
- 복잡한 인접 리스트 구성 로직이 직접 구현되어 있어 코드가 길어지고 유지보수가 어려울 수 있음

### 상세 피드백

제출된 코드는 트리 DP(Tree DP)와 그리디 알고리즘을 활용하여 매우 효율적으로 문제를 해결하였습니다. 각 정점마다 가능한 값인 $l_v$와 $r_v$ 두 가지 경우에 대해 하위 트리의 최대 가치를 상향식(Bottom-up)으로 계산하여 $O(N)$의 시간 복잡도 내에 모든 테스트 케이스를 통과할 수 있습니다. 또한, 재귀 호출을 사용하지 않고 반복문(BFS 순서 역순)을 통해 DP를 구현함으로써 파이썬의 재귀 깊이 제한(Recursion Limit) 문제를 우회하고 함수 호출 오버헤드를 줄였습니다. `sys.stdin.buffer.read`를 통한 빠른 입출력 처리도 매우 훌륭합니다. 다만 변수명(`a`, `b`, `nl`, `nr` 등)이 다소 직관적이지 않아 가독성이 떨어질 수 있으므로 주석을 보완하면 더욱 완벽한 코드가 될 것입니다.
