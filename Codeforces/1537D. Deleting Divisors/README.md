## 문제 설명

Alice와 Bob이 게임을 하고 있습니다. 그들은 양의 정수 $n$을 가지고 시작하며, 번갈아가며 연산을 수행합니다. 각 턴마다 플레이어는 현재 $n$의 약수 중 $1$과 $n$이 아닌 것 하나를 $n$에서 뺄 수 있습니다. 자신의 턴에 더 이상 움직일 수 없는 플레이어가 패배합니다. Alice가 항상 먼저 시작합니다. 각 턴마다 현재 수의 약수를 뺀다는 점에 유의하세요. 두 플레이어가 최적의 전략으로 게임을 플레이할 때, 누가 승리할지 구하세요.

## 입력

첫 번째 줄에는 테스트 케이스의 개수를 나타내는 단일 정수 $t$ ($1 \leq t \leq 10^4$)가 주어집니다. 그 후 $t$개의 테스트 케이스가 주어집니다. 각 테스트 케이스는 초기 정수를 나타내는 단일 정수 $n$ ($1 \leq n \leq 10^9$)을 포함합니다.

## 출력

각 테스트 케이스마다, 두 플레이어가 최적의 전략으로 게임을 플레이할 때 앨리스가 이긴다면 " Alice "를, 밥이 이긴다면 " Bob "을 출력한다.
