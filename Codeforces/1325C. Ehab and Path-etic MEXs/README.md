## 문제 설명

$n$개의 정점으로 이루어진 트리가 주어집니다. 트리의 간선들에 다음 조건을 만족하도록 번호를 매기려 합니다:
    모든 라벨은 $0$ 이상 $n-2$ 이하의 정수입니다.
    모든 라벨은 서로 다릅니다.
    모든 노드 쌍 $(u, v)$에 대한 $MEX(u,v)$의 최댓값이 가능한 작아야 합니다.
여기서 $MEX(u,v)$는 노드 $u$에서 노드 $v$로 가는 유일한 단순 경로 상의 간선들에 적히지 않은 가장 작은 음이 아닌 정수를 의미합니다.

## 입력

첫 번째 줄에는 트리의 정점의 개수를 나타내는 정수 $n$ ($2 \le n \le 10^5$)이 주어집니다. 이어지는 $n-1$개의 각 줄에는 정점 $u$와 $v$ 사이에 간선이 있음을 의미하는 두 개의 공백으로 구분된 정수 $u, v$ ($1 \le u,v \le n$)가 주어집니다. 주어진 그래프는 트리임이 보장됩니다.

## 출력

$n-1$개의 정수를 출력합니다. 그중 $i$번째 정수는 ($i$번째 입력된) $i$번째 간선에 적힌 수가 되어야 합니다.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(N)

### 잘한 점

- 트리의 차수를 분석하여 차수가 3 이상인 노드를 기준으로 0, 1, 2를 우선 할당하는 그리디 전략을 정확히 구현함
- 차수가 3 이상인 노드가 없는 경우(체인 형태의 트리)를 별도로 처리하여 MEX 최댓값을 0으로 최적화함
- 입력 순서대로 결과를 출력해야 하는 요구사항을 딕셔너리를 활용해 정확하고 깔끔하게 해결함
- 시간복잡도 O(N)과 공간복잡도 O(N)으로 매우 효율적인 코드를 작성함

### 개선할 점

- 변수 이름(route, dic 등)이 자료구조의 형태를 나타낼 뿐 의미를 명확히 전달하지 않아 약간의 아쉬움이 있음
- 입력이 많을 때 기본 input() 함수를 사용하므로 대규모 입력에서 속도가 중요한 경우 sys.stdin.readline을 사용하는 것이 더 안전함

### 상세 피드백

이 문제는 주어진 트리의 간선에 0부터 n-2까지의 레이블을 중복 없이 부여하여, 모든 경로 (u, v) 상의 간선 레이블이 이루는 집합의 MEX 값 중 최댓값을 최소화하는 구성적 알고리즘 문제입니다. 제출된 코드는 트리의 차수가 3 이상인 노드(스타 그래프의 중심 형태)가 존재하는지 확인하고, 존재한다면 해당 노드에 연결된 3개의 간선에 각각 0, 1, 2를 우선 할당한 뒤 나머지 간선에 순차적으로 3부터 n-2까지의 레이블을 채워넣는 아이디어를 아주 훌륭하게 구현했습니다. 만약 차수가 3 이상인 노드가 존재하지 않는다면(즉, 트리가 일직선 형태인 경우) 간선에 0부터 n-2까지 순서대로 레이블을 부여하여 MEX의 최댓값을 0으로 최소화합니다. 시간복잡도는 O(N)으로 최적이며, 공간복잡도 역시 O(N)으로 문제의 제약 조건을 완벽히 만족합니다. 입력 순서대로 정답을 출력하기 위해 딕셔너리를 사용해 간선의 인덱스를 관리한 점도 매우 지혜롭습니다. 전반적으로 가독성이 좋고 엣지 케이스까지 깔끔하게 처리된 모범적인 풀이입니다.
