## 문제 설명

길이가 $n$인 배열 $a$에 대하여 함수 $f(a)$를 $$f(a) = \textrm{cost} + (a_1 - a_2 + a_3 - a_4 \cdots a_n)$$으로 정의합시다. 여기서 $\textrm{cost}$의 초기값은 $0$입니다. 이제 앨리스와 밥에게 길이가 $n$인 배열 $a$가 주어지는 상황을 생각해 봅시다. 두 사람은 앨리스가 먼저 시작하여 번갈아가며 최대 $10^{100}$ 턴 동안 게임을 진행합니다. 각 턴마다 플레이어는 다음 연산 중 정확히 하나를 수행해야 합니다.

* 앨리스와 밥 모두 게임을 종료합니다.
* $1 \le l \le r \le n$을 만족하는 두 인덱스 $l, r$을 골라 $a_l$과 $a_r$을 교환합니다. 이 연산은 $\textrm{cost}$에 $(r - l)$을 더합니다.

앨리스는 $f(a)$를 최대화하려 하고, 밥은 최소화하려 한다고 가정합시다. 두 플레이어 모두 최적의 전략으로 플레이할 때, $f(a)$의 최종 값을 구하는 것이 여러분의 문제입니다.

## 입력

각 테스트 케이스는 여러 개의 테스트 케이스를 포함합니다. 첫 번째 줄에는 테스트 케이스의 수 $t$ ($1 \le t \le 10^4$)가 주어집니다. 이어서 테스트 케이스의 설명이 주어집니다. 각 테스트 케이스의 첫 번째 줄에는 배열 $a$의 길이인 단일 정수 $n$ ($1 \le n \le 2\cdot10^5$)이 주어집니다. 두 번째 줄에는 배열 $a$의 원소인 $n$개의 정수 $a_1,a_2,a_3,\ldots,a_n$ ($1 \le a_i \le 10^9$)이 주어집니다. 모든 test case에 대한 $n$의 합은 $2\cdot10^5$을 넘지 않는 것이 보장됩니다.

## 출력

각 테스트 케이스마다 단 하나의 정수를 출력합니다. 이는 두 플레이어가 최적의 전략으로 플레이할 때의 $f(a)$의 최종 값을 의미합니다.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(N)

- n이 작을 때 발생할 수 있는 엣지 케이스(best < 0 등)를 안전하게 처리했습니다.
