## 문제 설명

바스야는 이상한 장치를 발견했습니다. 장치의 전면 패널에는 빨간색 버튼, 파란색 버튼, 그리고 어떤 양의 정수를 보여주는 디스플레이가 있습니다. 빨간색 버튼을 누르면 장치는 디스플레이에 표시된 숫자에 $2$를 곱합니다. 파란색 버튼을 누르면 디스플레이에 표시된 숫자에서 $1$을 뺍니다. 만약 어떤 시점에서 숫자가 양의 정수가 아니게 되면, 장치는 고장 납니다. 디스플레이에는 임의로 큰 숫자가 표시될 수 있습니다. 처음에 디스플레이에는 숫자 $n$이 표시되어 있습니다. 봆은 디스플레이에 숫자 $m$을 띄우고자 합니다. 이 결과를 달성하기 위해 그가 해야 하는 최소 버튼 클릭 횟수는 얼마인가요?

## 입력

입력의 첫 번째이자 유일한 줄에는 공백으로 구분된 두 개의 서로 다른 정수 $n$과 $m$ ($1 \le n, m \le 10^{4}$)이 주어집니다.

## 출력

$n$에서 시작하여 버튼을 조작해 숫자 $m$을 만들기 위해 버튼을 눌러야 하는 최소 횟수 — 단 하나의 정수를 출력한다.
