## 문제 설명

론(Ron)은 길이 $n$인 순열 $a$를 가지고 있는 행복한 소유자입니다. 길이 $n$인 순열은 $1$부터 $n$까지의 서로 다른 정수 $n$개로 이루어진 임의의 순서의 배열입니다. 예를 들어 $[2,3,1,5,4]$는 순열이지만, $[1,2,2]$는 순열이 아니며($2$가 배열에 두 번 나타남), $[1,3,4]$도 순열이 아닙니다($n=3$인데 배열에 $4$가 있음). 

론의 순열은 ($r_i$, $p_i$) 형식의 $m$개의 실험을 받습니다. 이는 범위 $[1, r_i]$의 원소들(다시 말해, 길이가 $r_i$인 접두사)이 확률 $p_i$로 오름차순 정렬됨을 의미합니다. 모든 실험은 입력 데이터에 주어진 순서와 동일한 순서로 수행됩니다. 예시로, 순열 $[4, 2, 1, 5, 3]$과 실험 $(3, 0.6)$을 살펴봅시다. 이 실험을 거치면 $60\%$의 확률로 순열은 $[1, 2, 4, 5, 3]$ 형태로 바뀌고, $40\%$의 확률로 변경되지 않은 상태로 남습니다. 

$m$개의 실험이 모두 끝난 후 순열이 완전히 오름차순으로 정렬될 확률을 구해야 합니다.

## 입력

각 테스트 케이스는 하나 이상의 테스트 케이스를 포함합니다. 첫 번째 줄에는 테스트 케이스의 수 $t$ ($1 \le t \le 100$)가 주어집니다. 각 테스트 케이스의 첫 번째 줄에는 두 정수 $n$과 $m$ $(1 \le n, m \le 10^5)$이 주어지며, 각각 순열의 길이와 실험의 수를 의미합니다. 각 테스트 케이스의 두 번째 줄에는 순열의 원소를 나타내는 $n$개의 정수 $a_1, a_2, \ldots, a_n$ $(1 \le a_i \le n)$이 주어집니다. 이어서 주어지는 각 테스트 케이스의 $m$개의 줄에는 각각 정수 $r_i$와 실수 $p_i$ $(1 \le r_i \le n, 0 \le p_i \le 1)$가 주어지며, 이는 접두사의 길이와 그것이 정렬될 확률을 나타냅니다. 모든 확률은 소수점 아래 최대 $6$자리까지 주어집니다. 모든 테스트 케이스에 대한 $n$의 합과 $m$의 합은 $10^5$을 넘지 않는 것이 보장됩니다 ($\sum n, \sum m \le 10^5$).

## 출력

각 테스트 케이스마다 하나의 실수를 출력하세요. 이는 모든 실험이 끝난 후 순열이 오름차순으로 정렬될 확률입니다. 여러분의 답은 절대 오차나 상대 오차가 $10^{-6}$을 넘지 않아야 정답으로 인정됩니다. 형식적으로, 여러분의 답을 $a$, 정답을 $b$라고 할 때, $\frac{|a - b|}{\max{(1, |b|)}} \le 10^{-6}$을 만족하면 정답 처리됩니다.
