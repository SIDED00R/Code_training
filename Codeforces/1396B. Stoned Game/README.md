## 문제 설명

T는 그의 친구 HL과 게임을 하고 있습니다. $n$개의 돌 무더기가 있으며, $i$번째 무더기에는 처음에 $a_i$개의 돌이 있습니다. T와 HL은 번갈아 가며 턴을 진행하며, T가 먼저 시작합니다. 각 턴에서 플레이어는 비어 있지 않은 무더기를 선택한 다음, 그 무더기에서 하나의 돌을 제거합니다. 그러나 이전 턴에서 선택된 무더기는 선택할 수 없습니다 (다른 플레이어가 선택한 무더기이거나, 현재 턴이 첫 턴인 경우에는 플레이어가 비어 있지 않은 무더기 중 아무거나 선택할 수 있습니다). 자신의 턴에 무더기를 선택할 수 없는 플레이어는 패배하며, 게임은 종료됩니다. 두 플레이어가 최적으로 플레이한다고 가정할 때, $t$게임의 시작 구성에 따라 각 게임의 승자를 결정하세요.

## 입력

입력의 첫 번째 줄에는 단일 정수 $t$ $(1 \le t \le 100)$가 포함되어 있으며, 이는 게임의 수를 나타냅니다. 게임의 설명이 이어집니다. 각 설명은 두 줄로 구성됩니다: 첫 번째 줄에는 단일 정수 $n$ $(1 \le n \le 100)$가 포함되어 있으며, 이는 더미의 수를 나타냅니다. 두 번째 줄에는 $n$개의 정수 $a_1, a_2, \dots, a_n$ $(1 \le a_i \le 100)$가 포함됩니다.

## 출력

각 게임마다 승자의 이름인 " T " 또는 " HL " (따옴표 없이)을 한 줄에 출력하세요.
