## 문제 설명

정수 배열 $a_1, a_2, \ldots, a_n$과 $n$개의 문자로 이루어진 이진 문자열$^{\dagger}$ $s$가 주어집니다. Augustin은 자료구조의 열렬한 팬입니다. 그래서 그는 당신에게 $q$개의 쿼리를 처리할 수 있는 자료구조를 구현해 달라고 요청했습니다. 쿼리에는 두 가지 종류가 있습니다.

"1 $l$ $r$" ($1\le l \le r \le n$) — $l \le i \le r$를 만족하는 모든 $i$에 대해 문자 $s_i$를 그 반대 값으로 바꿉니다. 즉, 모든 $\texttt{0}$을 $\texttt{1}$로, 모든 $\texttt{1}$을 $\texttt{0}$으로 바꿉니다.

"2 $g$" ($g \in \{0, 1\}$) — $s_i = g$를 만족하는 모든 인덱스 $i$에 대해 수 $a_i$들의 비트 단위 XOR 값을 계산합니다. 공집합에 대한 $\operatorname{XOR}$ 값은 $0$으로 간주함에 유의하세요.

모든 쿼리에 답할 수 있도록 Augustin을 도와주세요!

예를 들어, $n = 4$, $a = [1, 2, 3, 6]$, $s = \texttt{1001}$일 때, 다음과 같은 일련의 쿼리를 생각해 봅시다.

"2 $0$" — $s_i = \tt{0}$을 만족하는 인덱스 $i$에 관심이 있는데, $s = \tt{1001}$이므로 이는 인덱스 $2$와 $3$입니다. 따라서 이 쿼리의 답은 $a_2 \oplus a_3 = 2 \oplus 3 = 1$이 됩니다.

"1 $1$ $3$" — 문자 $s_1, s_2, s_3$을 그 반대 값으로 바꿔야 합니다. 쿼리 전에는 $s = \tt{1001}$이고, 쿼리 후에는 $s = \tt{0111}$이 됩니다.

"2 $1$" — $s_i = \tt{1}$을 만족하는 인덱스 $i$에 관심이 있는데, $s = \tt{0111}$이므로 이는 인덱스 $2$, $3$, $4$입니다. 따라서 이 쿼리의 답은 $a_2 \oplus a_3 \oplus a_4 = 2 \oplus 3 \oplus 6 = 7$이 됩니다.

"1 $2$ $4$" — $s = \tt{0111}$ $\to$ $s = \tt{0000}$.

"2 $1$" — $s = \tt{0000}$이므로 $s_i = \tt{1}$인 인덱스가 존재하지 않습니다. 공집합에 대한 $\operatorname{XOR}$ 값은 $0$으로 간주하므로, 이 쿼리의 답은 $0$입니다.

$^{\dagger}$ 이진 문자열이란 $\texttt{0}$ 또는 $\texttt{1}$ 문자로만 이루어진 문자열입니다.

## 입력

입력의 첫 번째 줄에는 정수 $t$ ($1 \le t \le 10^4$)가 주어지며, 이는 테스트 케이스의 개수이다. 이어서 각 테스트 케이스의 설명이 주어진다. 각 테스트 케이스 설명의 첫 번째 줄에는 정수 $n$ ($1 \le n \le 10^5$)이 주어지며, 이는 배열의 길이이다. 테스트 케이스의 두 번째 줄에는 $n$개의 정수 $a_1, a_2, \dots, a_n$ ($1 \le a_i \le 10^9$)이 주어진다. 테스트 케이스의 세 번째 줄에는 길이 $n$인 이진 문자열 $s$가 주어진다. 테스트 케이스의 네 번째 줄에는 정수 $q$ ($1 \le q \le 10^5$)가 주어지며, 이는 쿼리의 개수이다. 이어지는 $q$개의 줄에는 테스트 케이스의 쿼리들이 설명된다. 각 쿼리의 첫 번째 숫자 $tp \in \{1, 2\}$는 쿼리의 유형을 나타내며, $tp = 1$이면 $2$개의 정수 $1 \le l \le r \le n$이 이어지고, 이는 매개변수 $l, r$을 사용하여 유형 $1$의 연산을 수행해야 함을 의미하며, $tp = 2$이면 정수 $g \in \{0, 1\}$ 하나가 이어지고, 이는 매개변수 $g$를 사용하여 유형 $2$의 연산을 수행해야 함을 의미한다. 모든 테스트 케이스에 대한 $n$의 합은 $10^5$를 넘지 않으며, 또한 모든 테스트 케이스에 대한 $q$의 합도 $10^5$를 넘지 않음이 보장된다.

## 출력

각 테스트 케이스에 대해, 그리고 그 안에 있는 각 $2$ 유형 질의에 대해, 해당 질의에 대한 답을 출력하세요.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(N + Q) per test case (전체 합산 시 O(sum(N+Q)))

### 잘한 점

- XOR의 자기상쇄 성질을 이용해 구간 반전 업데이트를 O(1)로 처리하는 핵심 아이디어를 정확히 구현함
- prefix XOR 배열을 사전 계산하여 구간 XOR 쿼리를 O(1)에 해결
- sys.stdin.buffer.read()와 결과 리스트 join 출력으로 Python에서 흔히 발생하는 I/O 병목을 효과적으로 회피함
- empty set XOR=0 같은 엣지 케이스가 X^ans1 공식에 의해 자연스럽게 처리됨

### 개선할 점

- 초기 ans1을 계산하는 for 루프가 순수 파이썬 레벨로 동작하여, N이 매우 크고 여러 테스트케이스가 있을 경우 약간의 오버헤드가 있을 수 있음 (다만 O(N)이라 치명적이지 않음)
- 변수명 ans1, X 등이 다소 축약되어 있어 가독성 측면에서 ans_one_count, total_xor 같은 조금 더 명시적인 이름을 쓰면 유지보수에 유리함
- 멀티 테스트케이스 입력 처리 시 all data를 한꺼번에 읽는 것은 좋지만, 코드에 주석으로 입력 형식(예: t가 테스트케이스 수라는 점)을 명확히 밝혀주면 이해가 쉬움

### 상세 피드백

이 문제는 태그에 binary search, dp, data structures 등이 붙어있지만, 실제로는 XOR 연산의 성질(토글 연산이 자기 자신을 상쇄시키는 특성)을 이용하면 세그먼트 트리나 복잡한 자료구조 없이도 O(1) 업데이트/쿼리로 풀 수 있는 문제입니다. 제출 코드는 이 핵심 아이디어를 정확히 파악하고 있습니다.

구체적으로, prefix XOR 배열을 미리 구해두고, 구간 [l,r]을 반전시킬 때 '1인 인덱스들의 XOR 합(ans1)'에 해당 구간의 XOR 값(prefix[r]^prefix[l-1])을 XOR해주는 방식으로 O(1)에 업데이트를 처리합니다. 이는 반전으로 인해 1→0, 0→1이 되는 원소들이 교환되면서 ans1에 정확히 해당 구간의 XOR만큼 변화가 생긴다는 성질을 이용한 것으로, 매우 우아하고 효율적인 접근입니다.

쿼리 타입 2에서도 g=0인 경우 전체 XOR(X)에서 ans1을 XOR해서 구하는 것 역시 XOR의 역원이 자기 자신이라는 성질을 활용한 올바른 처리입니다. 빠른 입출력(sys.stdin.buffer.read()와 리스트 조인 후 한번에 출력)도 적용되어 있어 Python 환경에서도 TLE 위험이 낮습니다.

다만 초기 ans1을 계산하는 부분에서 파이썬 레벨의 for 루프를 사용하는데, N이 매우 큰 경우(예: 2*10^5 이상) 약간의 성능 저하가 있을 수 있으나, 이 역시 O(N)이므로 전체 복잡도에는 영향이 없습니다. 전반적으로 문제의 핵심을 정확히 파악한 최적의 풀이입니다.
