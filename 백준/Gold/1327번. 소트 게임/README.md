## 문제 설명

홍준이는 소트 게임을 하려고 한다. 소트 게임은 1부터 N까지 정수로 이루어진 N자리의 순열을 이용한다. 이 게임에선 K가 주어진다. 어떤 수를 뒤집으면, 그 수부터 오른쪽으로 K개의 수를 뒤집어야 한다. 예를 들어, 순열이 5 4 3 2 1 이었고, 여기서 K가 3일 때, 4를 뒤집으면 5 2 3 4 1이 된다. 반드시 K개의 수를 뒤집어야하기 때문에, 처음 상태에서 2나 1을 선택하는 것은 불가능하다.
입력으로 들어온 순열을 오름차순으로 만들려고 한다. 게임을 최대한 빨리 끝내고 싶을 때, 수를 최소 몇 개 선택해야 하는지 구해보자.

## 입력

첫째 줄에 순열의 크기 N과 K가 주어진다. 둘째 줄에 순열에 들어가는 수가 주어진다.

## 출력

첫째 줄에 정답을 출력한다. 만약 오름차순으로 만들 수 없으면 -1을 출력한다.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(N! * N) 시간, O(N! * N) 공간 (N은 순열의 길이, 보통 N ≤ 8로 제한됨)

### 잘한 점

- N이 작다는 제약을 활용해 전체 순열을 노드로 하는 BFS로 최단 연산 횟수를 정확히 계산함
- dict(dic)를 방문 체크와 거리 저장용으로 동시에 활용하여 코드가 간결하고 메모리 접근이 O(1)에 가까움
- 도달 불가능한 경우(-1)와 정상 종료 케이스를 모두 올바르게 처리함

### 개선할 점

- if ... continue / else 구조가 불필요하게 길어서 'if change_line not in dic:' 형태로 단순화할 수 있음
- 변수명 now_weight가 BFS의 '거리(depth)' 의미를 바로 드러내지 못해 가독성이 떨어짐
- N이 매우 커질 경우(제약이 느슨해질 경우) N! 상태 폭발로 메모리/시간 초과 위험이 있다는 점을 주석 등으로 명시하지 않음

### 상세 피드백

이 문제는 N이 작게 제한되어 있어(보통 8 이하) 전체 순열 상태 공간을 BFS로 탐색하는 것이 정석적인 풀이입니다. 제출 코드는 deque와 dict를 이용해 각 순열 상태를 노드로, '구간 K개를 뒤집는 연산'을 엣지로 보고 BFS를 수행하며, dic에 방문 여부와 거리(가중치)를 동시에 저장하는 방식이 깔끔합니다. 정렬된 순열에 도달하면 dic에서 거리를 꺼내 1을 빼서(시작 상태의 가중치 1을 보정) 출력하고, 도달 불가능하면 -1을 출력하는 로직도 정확합니다.

다만 몇 가지 보완하면 좋을 점이 있습니다. if/else 구조에서 'if change_line in dic: continue / else: ...' 대신 'if change_line not in dic:' 형태로 작성하면 불필요한 continue 없이 더 간결해집니다. 또한 변수명 now_weight보다는 now_dist(거리) 같은 이름이 BFS 맥락에 더 직관적입니다. 탭과 스페이스가 혼용되어 있을 수 있으니 PEP8에 맞춰 일관된 들여쓰기를 쓰는 것이 좋습니다. 전체적으로 BFS 기반 상태 탐색이라는 핵심 아이디어는 정확하고 효율적으로 구현되어 있습니다.
