## 문제 설명

수빈이는 동생과 숨바꼭질을 하고 있다. 수빈이는 현재 점 N(0 ≤ N ≤ 100,000)에 있고, 동생은 점 K(0 ≤ K ≤ 100,000)에 있다. 수빈이는 걷거나 순간이동을 할 수 있다. 만약, 수빈이의 위치가 X일 때 걷는다면 1초 후에 X-1 또는 X+1로 이동하게 된다. 순간이동을 하는 경우에는 1초 후에 2*X의 위치로 이동하게 된다.
수빈이와 동생의 위치가 주어졌을 때, 수빈이가 동생을 찾을 수 있는 가장 빠른 시간이 몇 초 후인지 구하는 프로그램을 작성하시오.

## 입력

첫 번째 줄에 수빈이가 있는 위치 N과 동생이 있는 위치 K가 주어진다. N과 K는 정수이다.

## 출력

첫째 줄에 수빈이가 동생을 찾는 가장 빠른 시간을 출력한다.
둘째 줄에 어떻게 이동해야 하는지 공백으로 구분해 출력한다.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(N) 시간, O(N) 공간 (N은 최대 좌표 범위 100,000, 배열 크기는 200,000으로 설정)

### 잘한 점

- BFS와 부모 포인터를 결합해 최단 시간과 이동 경로를 동시에 구하는 표준적이고 효율적인 접근을 사용함
- 이동 범위(걷기 좌우, 순간이동) 각각에 대해 배열 경계 체크를 꼼꼼히 수행하여 인덱스 에러를 방지함
- N=K인 경우에도 dp[n]=n 자기참조 트릭으로 별도의 분기 없이 자연스럽게 처리됨

### 개선할 점

- dp라는 변수명이 실제 역할(부모 노드 저장 및 방문 체크)과 맞지 않아 가독성이 떨어짐 (parent, visited 등이 더 적절)
- 200000이라는 매직 넘버가 하드코딩되어 있어 왜 이 값을 사용했는지 코드만 봐서는 파악하기 어려움
- while dp[k] == -1 조건으로 루프를 도는데, K가 이미 N과 같을 때는 진입 자체를 안 하는 구조라 의도된 엣지케이스 처리인지 주석으로 명시했으면 더 좋았을 것
- 변수명 out, now 등이 다소 축약되어 있어 전체적인 코드 흐름을 이해하는 데 약간의 추가 사고가 필요함

### 상세 피드백

이 문제는 가중치 없는 그래프에서 최단 경로와 그 경로의 역추적을 요구하므로 BFS + parent 포인터 기법이 표준적이고 최적인 해법입니다. 제출 코드는 dp 배열을 '방문 여부 + 부모 노드' 역할로 이중 활용해 BFS를 수행하고, 역추적으로 경로를 복원하는 정석적인 구조를 따르고 있습니다. 시간복잡도는 O(N)으로 그래프 탐색 문제에 적합한 수준이며, 더 빠른 알고리즘은 존재하지 않습니다.

다만 세부적으로 개선할 점이 있습니다. dp라는 변수명은 일반적으로 '동적 계획법 테이블'을 떠올리게 하는데, 실제로는 '방문 체크 + 부모 노드 저장' 역할을 겸하고 있어 가독성 면에서 parent나 visited 같은 이름이 더 명확합니다. 또한 배열 크기 200000이 하드코딩되어 있는데, 이는 K가 최대 100000이고 2*100000까지 고려해야 한다는 전제에서 나온 값이지만 주석 없이는 왜 200000인지 파악하기 어렵습니다. N=K인 엣지케이스는 dp[n]=n으로 자기참조시켜 while 루프에 진입하지 않고 바로 역추적 루프도 종료되므로 정상 동작하지만, 이런 자기참조 트릭에 대한 설명이 코드에 없어 다른 사람이 읽을 때 혼동될 수 있습니다.

전반적으로 알고리즘 선택과 구현은 훌륭하며, 교육적으로 참고할 만한 BFS+경로역추적 패턴을 잘 보여주고 있습니다.
