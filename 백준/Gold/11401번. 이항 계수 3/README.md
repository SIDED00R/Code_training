## 문제 설명

자연수 \(N\)과 정수 \(K\)가 주어졌을 때 이항 계수 \(\binom{N}{K}\)를 1,000,000,007로 나눈 나머지를 구하는 프로그램을 작성하시오.

## 입력

첫째 줄에 \(N\)과 \(K\)가 주어진다. (1 ≤ \(N\) ≤ 4,000,000, 0 ≤ \(K\) ≤ \(N\))

## 출력

\(\binom{N}{K}\)를 1,000,000,007로 나눈 나머지를 출력한다.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: 시간: O(N) 전처리 + O(1) 질의, 공간: O(N)

### 잘한 점

- O(N) 전처리 + O(1) 질의로 이론적으로 최적에 가까운 알고리즘을 정확히 구현함
- 페르마의 소정리를 이용해 모듈러 역원을 단 한 번의 거듭제곱 연산으로 구하고, 나머지는 역산으로 O(1)씩 처리하는 효율적인 기법을 사용함
- comb 함수에서 r<0, r>n 같은 범위 체크를 통해 잠재적 엣지케이스를 방어적으로 처리함

### 개선할 점

- 입력값 K를 의미하는 변수명이 r로 되어 있어 N, K와의 매핑이 직관적이지 않음
- N이 4,000,000까지 가는 상황에서 순수 Python for 루프 두 번(총 800만 회 가까운 반복)을 수행하므로, 환경에 따라 시간 초과 위험이 있어 PyPy 제출이나 입출력 최적화(sys.stdin) 고려가 필요함
- input()을 그대로 사용하고 있어 대용량 입력 처리에는 sys.stdin.readline이 더 안전함(이 문제는 입력이 한 줄뿐이라 큰 영향은 없음)

### 상세 피드백

N이 최대 4,000,000으로 매우 크기 때문에, 이항계수를 구할 때 파스칼의 삼각형(O(N^2))이나 매번 pow로 역원을 구하는 방식(O(N log MOD))은 모두 시간 초과가 날 가능성이 높습니다. 제출 코드는 팩토리얼과 팩토리얼의 역원을 각각 O(N)에 전처리한 뒤, 페르마의 소정리를 이용해 fact[N]의 역원 하나만 모듈러 거듭제곱으로 계산하고 나머지는 재귀적으로 역산(inv_fact[i-1] = inv_fact[i] * i % MOD)해 구하는 표준적인 O(N) 전처리 + O(1) 질의 기법을 정확히 사용하고 있습니다. 이는 이 문제에 대해 알려진 가장 효율적인 접근법으로, 알고리즘 선택 자체는 매우 적절합니다.

다만 실행 속도 측면에서 주의할 점이 있습니다. N=4,000,000일 때 순수 Python의 for 루프로 두 번(fact, inv_fact)의 4백만 회 반복과 모듈러 곱연산을 수행하는데, CPython 인터프리터 특성상 이는 상당히 느릴 수 있습니다. 백준 Python3 제출 시 시간 제한이 여유 있게 주어지는 경우가 많지만, 환경에 따라 TLE가 발생할 수 있으므로 PyPy로 제출하거나, sys.stdin.readline을 사용해 입력 처리를 최적화하거나, 리스트 컴프리헨션/itertools.accumulate 등을 활용해 루프를 벡터화하는 것을 고려해볼 수 있습니다. 또한 N=0 입력이 들어오는 경우는 제약 조건상 N≥1이라 문제가 없지만, 혹시 몰라 방어적으로 처리된 것은 좋은 습관입니다.

코드 가독성 면에서는 변수명 r이 K를 의미하는데 다소 혼동을 줄 수 있어 K로 통일하면 더 명확했을 것입니다. 전체적으로 알고리즘적 완성도는 높고, 이 문제의 정석 풀이를 정확히 구현했다고 평가할 수 있습니다.
