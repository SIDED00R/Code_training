## 문제 설명

정수를 저장하는 큐를 구현한 다음, 입력으로 주어지는 명령을 처리하는 프로그램을 작성하시오.
명령은 총 여섯 가지이다.
push X: 정수 X를 큐에 넣는 연산이다.
pop: 큐에서 가장 앞에 있는 정수를 빼고, 그 수를 출력한다. 만약 큐에 들어있는 정수가 없는 경우에는 -1을 출력한다.
size: 큐에 들어있는 정수의 개수를 출력한다.
empty: 큐가 비어있으면 1, 아니면 0을 출력한다.
front: 큐의 가장 앞에 있는 정수를 출력한다. 만약 큐에 들어있는 정수가 없는 경우에는 -1을 출력한다.
back: 큐의 가장 뒤에 있는 정수를 출력한다. 만약 큐에 들어있는 정수가 없는 경우에는 -1을 출력한다.

## 입력

첫째 줄에 주어지는 명령의 수 N (1 ≤ N ≤ 2,000,000)이 주어진다. 둘째 줄부터 N개의 줄에는 명령이 하나씩 주어진다. 주어지는 정수는 1보다 크거나 같고, 100,000보다 작거나 같다. 문제에 나와있지 않은 명령이 주어지는 경우는 없다.

## 출력

출력해야하는 명령이 주어질 때마다, 한 줄에 하나씩 출력한다.

## 코드 리뷰

- 효율성: 효율적
- 시간복잡도: O(N)

### 잘한 점

- deque를 사용해 모든 큐 연산을 O(1)에 처리하여 시간복잡도 상 최적의 자료구조를 선택함
- sys.stdin.readline으로 입력을 재정의하여 대량 입력에 대한 처리 속도를 확보함
- 큐가 빈 경우에 대한 예외 처리(-1 출력, empty 1 출력 등)를 모든 분기에서 빠짐없이 처리함

### 개선할 점

- N이 최대 2,000,000인 상황에서 매번 print()를 호출하면 출력 오버헤드가 커져 시간 초과 위험이 있으므로, 결과를 리스트에 모아 한 번에 출력하는 방식이 더 안전함
- 명령어 비교 방식이 문자열 전체 비교(line == "front")와 split() 기반 분기가 혼용되어 있어 일관성이 다소 떨어짐
- 변수명 out, line 등은 문제 없지만 명령어 처리 순서를 분기 빈도나 가독성 측면에서 더 명확히 구조화할 수 있음(예: 명령어 첫 토큰만 추출해 분기)

### 상세 피드백

deque를 사용하여 push/pop/front/back/size/empty 모든 연산을 O(1)에 처리하고 있어 큐 자료구조 구현의 정석적인 풀이입니다. N이 최대 2,000,000까지 주어지는 만큼 입출력 속도가 중요한데, sys.stdin.readline을 input으로 재정의하여 입력 속도를 최적화한 점도 적절합니다. 다만 출력 부분에서 매 명령마다 print()를 호출하고 있는데, 이는 각 호출마다 내부 버퍼 flush 오버헤드가 발생할 수 있어 N이 최대치에 가까울 경우 시간 초과의 위험이 있습니다. 결과를 리스트에 모아두었다가 마지막에 sys.stdout.write('\n'.join(map(str, results)))로 한 번에 출력하면 훨씬 빠릅니다. 또한 명령어를 split으로 분기하지 않고 line == "front" 등 문자열 전체 비교와 line.split()을 혼용하고 있는데, 모든 줄을 split()으로 통일하면 로직이 더 깔끔해지고 "push" 뒤에 공백이 여러 개 있는 경우 등 예외 상황에도 더 안정적으로 대응할 수 있습니다. 전반적으로 자료구조 선택과 로직 자체는 우수하며, 출력 방식만 개선하면 더욱 견고한 풀이가 될 것입니다.
